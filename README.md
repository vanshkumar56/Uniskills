## About the Project

UniSkills aims to create a unified platform where students can discover opportunities, participate in practical challenges, track their progress, and connect with mentors and alumni.

Rather than focusing solely on certificates, UniSkills encourages students to develop demonstrable skills through hands-on experiences, collaboration, and continuous improvement.

## The Problem

Students often face several challenges while trying to build their careers:

- **Scattered opportunities:** Hackathons, internships, competitions, and challenges are spread across multiple platforms.
- **Skill–opportunity gap:** Students struggle to demonstrate practical skills beyond academic grades and certificates.
- **Limited mentorship:** Access to experienced mentors and alumni can be difficult.
- **Low engagement:** Traditional learning platforms often lack interactive experiences that encourage consistent skill development.
- **Disconnected communities:** Students, mentors, alumni, and institutions frequently operate in separate ecosystems.

## Our Solution

UniSkills brings opportunity discovery, practical learning, mentorship, and student communities together in one ecosystem.

The platform combines gamified learning, hands-on challenges, skill development, and community-driven growth to help students discover their strengths and connect their abilities with real-world opportunities.

## Key Features

### Opportunity Discovery

A central place to explore hackathons, internships, competitions, projects, and other student opportunities.

### Gamified Skill Development

Encourage continuous learning through challenges, progress tracking, achievements, and leaderboards.

### Practical Challenges

Help students demonstrate their skills by solving problems, completing tasks, and working on real-world projects.

### Mentorship Network

Connect students with mentors who can offer guidance, feedback, and career insights.

### Alumni Community

Enable alumni to reconnect with students, share experiences, provide guidance, and highlight relevant opportunities.

### Skill Profiles and Progress

Give students a way to showcase their skills, projects, interests, achievements, and learning progress.

### Intercollegiate Collaboration

Encourage students across institutions to collaborate, compete, learn, and grow together.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd <YOUR_PROJECT_FOLDER>
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the application.
